# Промпт: Сравнение версий договора с пометкой рисков

## Назначение

На вход — две версии договора (текст). На выход — список изменений с пометкой риска для каждого.

Это **единственный** промпт, который мы делаем на Opus, потому что здесь нужны рассуждения и оценка рисков, не просто извлечение.

## Версия

v1 (2026-05-05)

## Модель

`anthropic/claude-opus-4.6`

## Параметры

```
temperature: 0.1
max_tokens: 2500
```

## Этап 1 — детерминированный текстовый diff

Сначала Python-библиотекой `difflib` строим список изменённых блоков:

```python
import difflib
дифф = list(difflib.unified_diff(
    стар_версия.splitlines(),
    нов_версия.splitlines(),
    lineterm=''
))
```

Это сырой текстовый diff, который мы подаём LLM.

## Этап 2 — LLM группирует изменения и оценивает риски

### Системный промпт

```
Ты — юрист-помощник в фармацевтической компании. Тебе дают текстовый diff двух версий договора. Твоя задача — превратить технический diff в человеческий список изменений с оценкой риска.

Правила:
1. Сгруппируй мелкие правки одного смыслового блока в одну запись (например, переформулировка одного пункта = одно изменение).
2. Для каждого изменения укажи:
   - Что было / что стало (1-2 предложения)
   - Категория: финансы / срок / объём / гарантии / штрафы / прочее
   - Риск: низкий / средний / высокий
3. Высокий риск — это:
   - Увеличение срока оплаты для нашей стороны
   - Уменьшение штрафов с поставщика
   - Расширение ответственности нашей стороны
   - Сужение гарантий поставщика
4. Игнорируй косметические правки (опечатки, форматирование).
5. Сортируй: сначала высокий риск, потом средний, потом низкий.
```

### User-промпт (template)

```
Договор № {номер}, сделка {название_сделки}

Сравниваем версии:
- v{старая}: загружена {дата_старой}
- v{новая}: загружена {дата_новой}

Технический diff:
---
{unified_diff}
---

Сгруппируй и оцени.
```

## Тест-фикстуры

`тесты/фикстуры/сравнение-версий/`:
- `срок-оплаты-увеличен.txt` x2 → ожидаем высокий риск
- `штрафы-снижены.txt` x2 → ожидаем высокий риск
- `только-косметика.txt` x2 → ожидаем «изменения отсутствуют» / низкий риск
