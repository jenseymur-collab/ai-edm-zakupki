# Промпт: Анализ задержек согласования и рекомендации

## Назначение

Найти документы, которые висят на согласовании дольше нормы, и для каждого:
1. Объяснить, на ком и почему задержка.
2. Дать конкретную рекомендацию по ускорению.

## Версия

v1 (2026-05-05)

## Модель

`anthropic/claude-sonnet-4.5`

## Этап 1 — детерминированный (без LLM)

Для каждого активного документа со статусом `на согласовании`:

```python
просрочки = []
для каждого активного шага маршрута:
    время_на_шаге = now() - предыдущая_виза.создана  # или загрузка_документа для первого шага
    норма = шаг.срок_дни
    если время_на_шаге > норма:
        просрочки.append({
            "документ_id": ...,
            "шаг_роль": ...,
            "ответственный_id": ...,
            "перепростой_дни": (время_на_шаге - норма).days,
            "норма_дни": норма
        })
```

## Этап 2 — LLM формирует объяснение и рекомендации

### Системный промпт

```
Ты — ассистент менеджера закупок. Тебе дают список просроченных согласований по конкретной сделке. Твоя задача — кратко объяснить каждую задержку и дать конкретную рекомендацию.

Правила:
1. Для каждой задержки: одно предложение объяснения + одна конкретная рекомендация.
2. Рекомендации должны быть actionable: «написать N», «эскалировать M», а не «улучшить процесс».
3. Если по конкретному человеку висит несколько документов — упомяни это, это паттерн.
4. Не более 1 короткого абзаца на сделку.
```

### User-промпт (template)

```
Сделка: {номер_сделки}, {название_сделки}
Поставщик: {поставщик}
Сумма: {сумма} {валюта}

Просроченные шаги согласования:

{для каждой просрочки}
- Документ: {тип} № {номер}
  Шаг: {роль} (ожидаем визу)
  Ответственный: {имя}, роль {роль_пользователя}
  Перепростой: {дни} дн. сверх нормы ({норма} дн.)
{/для}

Дополнительно: ниже список других задержек по этому же ответственному (если есть):
{список_задержек_по_ответственным}

Дай краткое объяснение и рекомендации.
```

## Формат ответа frontend-у

```json
{
  "сделка_id": "...",
  "просрочки": [
    {
      "документ_id": "...",
      "тип": "договор",
      "ответственный": "Иванов И. И.",
      "перепростой_дни": 3,
      "ai_объяснение": "Иванов держит этот договор 7 дней при норме 4 — у него также висят ещё 2 договора с похожим перепростоем.",
      "ai_рекомендация": "Эскалировать руководителю финансов: системная задержка по этому ответственному."
    }
  ],
  "общий_паттерн": "По ответственному Иванову И. И. — 3 одновременных просрочки, требуется эскалация."
}
```

## Тест-фикстуры

В `тесты/фикстуры/задержки/`:
- `сценарий-1-простая-просрочка.json` → input + expected
- `сценарий-2-паттерн-по-ответственному.json` → проверка, что AI замечает паттерн
