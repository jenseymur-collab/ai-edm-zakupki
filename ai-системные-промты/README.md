# AI-системные промты

Здесь — промпты, которые **сервис** шлёт в LLM из кода. Это **не** наша переписка (она в `промты/`).

## Зачем выносить в отдельную папку

1. Промпт — это часть бизнес-логики. Его надо ревьюить так же, как код.
2. Версионирование промптов: «после правки промпта `извлечение-полей.md` v3 точность выросла с 82% до 91%».
3. Один промпт — один файл. Легко найти, легко править, легко тестировать.
4. Из кода загружаем как файл — не хардкодим строки в Python/JS.

## Состав

```
ai-системные-промты/
├── извлечение-полей.md             # промпт для парсинга документа в JSON
├── семантический-поиск.md          # rephrase запроса + RAG-ответ
├── анализ-задержек.md              # рекомендации по ускорению согласования
├── проверка-комплектности.md       # проверка соответствия документов сделке
└── сравнение-версий.md             # diff договоров с пометкой рисков
```

## Шаблон промпт-файла

```
# Промпт: [название]

## Назначение
Что эта функция делает.

## Версия
v1 (2026-05-05)

## Входные параметры
- {document_text} — полный текст документа
- {document_type} — тип из 7 возможных

## Системный промпт
[текст]

## User-промпт (template)
[текст с плейсхолдерами {...}]

## Ожидаемый формат ответа
JSON по схеме: ...

## Тест-фикстуры
См. `тесты/фикстуры/[имя]/`

## История изменений
- v1: первая версия
```
