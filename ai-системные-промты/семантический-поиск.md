# Промпт: Семантический поиск с RAG-ответом

## Назначение

Пользователь вводит запрос на естественном языке («договор с Pharma Corp на парацетамол»).
Система:
1. Превращает запрос в вектор.
2. Находит топ-N похожих документов в pgvector.
3. Просит LLM сформировать короткий человеческий ответ на основе найденного.

## Версия

v1 (2026-05-05)

## Модели

- Embeddings: `openai/text-embedding-3-small`
- Chat: `anthropic/claude-sonnet-4.5`

## Параметры

```
embedding: dimensions=1536
chat: temperature=0.2, max_tokens=500
```

## Поиск (этап 1)

Сначала превращаем запрос в вектор и ищем top-5 в pgvector:

```sql
SELECT документы.*, эмбеддинги.вектор <=> :запрос_вектор AS расстояние
FROM документы
JOIN эмбеддинги ON эмбеддинги.документ_id = документы.id
WHERE документы.активная = true
ORDER BY расстояние ASC
LIMIT 5;
```

## Системный промпт для chat (этап 2)

```
Ты — ассистент по навигации в системе документооборота закупок фармацевтической компании.

Задача: на основе найденных документов дать пользователю короткий, точный ответ на его запрос.

Правила:
1. Используй ТОЛЬКО информацию из переданных документов.
2. Если в документах нет ответа — честно скажи «не нашлось».
3. В ответе ссылайся на документы по их номерам и типу (например, «Договор № ДГ-25/04 от 15.04.2026»).
4. Не более 3–4 предложений в ответе.
5. Не выдумывай — лучше короткий ответ, чем длинный с предположениями.
```

## Тест-фикстуры

В `тесты/фикстуры/поиск/`:
- `сценарий-1-договор.txt` → запрос + ожидаемый top-1 документ_id
- `сценарий-2-нет-ответа.txt` → запрос на тему, которой нет → AI должен сказать «не нашлось»
