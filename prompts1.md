## 5. Уточнение про «дорого»

> погоди, скоро вернусь с информацией по токенам

> я вернулась ) итак, токены мне предоставили вот на этом сервисе: https://openrouter.ai

> вот информация по токенам: { "data": { ... "limit": 90, "limit_remaining": 90, "is_free_tier": false, ... } }

**Результат:** AI расшифровал JSON: $90 баланс, бессрочный, платный. Объяснил, что Claude.ai-подписка ≠ API, поэтому OpenRouter — оптимально (один ключ, все модели, без зарубежной карты). Прикинул реальный бюджет MVP: $5–15 при гибриде Sonnet+Opus, $50–100 если везде Opus.
