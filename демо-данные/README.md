# Демо-данные

Синтетические данные для демонстрации MVP. Никаких реальных коммерческих данных.

## Цель

К моменту демо у нас должны быть закрытые сценарии, на которых видна **каждая** функция системы:

| Сценарий | Что демонстрирует |
|---|---|
| Сделка с полным комплектом, согласована | Happy path, дашборд комплектации = 100% |
| Сделка с просрочкой согласования | AI-анализ задержек |
| Сделка без КП и без акта | Проверка комплектности, AI указывает пробелы |
| Договор с двумя версиями | Версионирование, AI-сравнение версий |
| Поиск «договор с поставщиком X на субстанцию Y» | Семантический поиск |

## Состав

```
демо-данные/
├── закупки.json            # сделки и поставщики
├── документы/              # тексты документов (.txt) — без сканов
│   ├── заявки/
│   ├── кп/
│   ├── протоколы/
│   ├── договоры/
│   ├── спецификации/
│   ├── акты/
│   └── счета-фактуры/
├── пользователи.json       # mock-юзеры для демо согласований
└── seed.py (или seed.ts)   # скрипт, который заливает всё в БД
```

## Контекст

Фарма-компания полного цикла. Поставщики: производители АФИ (активных фармацевтических ингредиентов), вспомогательных веществ, упаковки, лабораторного оборудования, реагентов.

Примеры МНН/субстанций для синтетики: парацетамол, омепразол, метформин, амоксициллин (это базовые, общеизвестные — для демо безопасно).

## Генерация

Тексты документов генерируем через LLM по нашему шаблону, затем правим вручную несколько штук, чтобы AI-извлечение полей выглядело естественно (не «слишком чисто»).
