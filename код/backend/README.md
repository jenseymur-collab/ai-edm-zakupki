# Backend — AI-EDM Закупки

FastAPI-приложение, доменные модули, AI-слой.

## Структура

```
backend/
├── pyproject.toml          # зависимости и метаданные пакета
├── Dockerfile              # как собирается образ
├── app/                    # исходный код
│   ├── главный.py          # точка входа FastAPI
│   ├── api/                # HTTP-роуты (агрегатор + здоровье)
│   ├── общее/              # config, логирование, БД, LLM-клиент
│   └── модули/             # доменные модули (заполняется в Фазе 2)
└── тесты/                  # backend-тесты
```
