Общий контекст  
Ваша задача — разработать полноценный веб-сервис с интеграцией AI по описанному заданию и задеплоить его.  
  
Главное в этом задании — не академические знания, а умение создавать продукт от идеи до деплоя: делать это красиво, быстро, инновационно и с AI.  
  
Важно: в задании описана база, которая ожидается по итогу. Если хотите сделать больше и лучше — это только приветствуется. Отраслевую методологию можете генерировать с помощью AI или брать из опыта. Тестовые данные и контекст — на вашей стороне, возможностей уточнения нет. Во всех заданиях предполагается контекст фармацевтической компании полного цикла, данные хранятся в разрозненных системах компании.  
  
  
Легенда  
Закупочный процесс сопровождается потоком документов: заявки, коммерческие предложения, протоколы выбора, договоры, спецификации, акты, счета-фактуры. Документы согласовываются по email, теряются в почте, а поиск нужного файла для аудита занимает часы. Нет единого хранилища с прозрачной историей согласований. Нужен сервис, который ведёт полный цикл документов закупки и помогает AI-навигацией и автоматизацией. Все необходимые данные для демонстрации создаются самостоятельно — используйте синтетические или сгенерированные через AI данные.  
  
  
Функциональные требования  
1. Типы документов: заявка на закупку, КП, протокол выбора, договор, спецификация, акт, счёт-фактура  
2. Связи: привязка документов к закупке, поставщику, контракту — единая карточка сделки  
3. Workflow согласования: маршруты по типу документа и сумме, электронные визы (упрощённо)  
4. Версионирование: история изменений, сравнение версий договора  
5. AI-поиск: нахождение документа по описанию задачи или контексту («договор с поставщиком X на субстанцию Y»)  
6. AI-извлечение данных: автоматическое определение ключевых полей из текста вставленного документа (копипаст или текстовый файл)  
7. Дашборд: документы на согласовании, просрочки, полнота комплектации по сделкам  
  
  
Требования к AI  
* Семантический поиск документов по контексту, а не только по ключевым словам  
* Извлечение структурированных данных из неструктурированных документов (суммы, даты, стороны)  
* Выявление задержек в согласовании и рекомендации по ускорению  
* Автоматическая проверка комплектности документов по сделке  
  
  
Что нужно приложить  
1. Ссылка на работающее приложение — задеплоенный сервис, доступный по URL  
2. Ссылка на репозиторий — GitHub с историей коммитов  
3. README.md — файл в формате .md (описание, архитектура, принятые решения, инструкция по запуску)  
4. PROMPTS.md — файл в формате .md с историей промптов, которые вы писали AI-агенту
