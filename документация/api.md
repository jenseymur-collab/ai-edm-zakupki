# API: список эндпоинтов

Это план API. Полный реальный список с примерами запросов будет автоматически доступен через Swagger по `/docs` после Фазы 1 (FastAPI генерирует сам).

## Соглашения

- База: `/api/v1`
- Формат: JSON
- Авторизация (mock): заголовок `X-User-Id` (UUID mock-пользователя)
- Идемпотентность для мутаций: заголовок `Idempotency-Key` (UUID)
- Ошибки: единый формат `{ "error": { "code": "...", "message": "...", "details": {...} } }`

## Принципы валидации

- Любой эндпоинт с UUID-параметром валидирует UUID (формат + существование).
- POST/PATCH-эндпоинты валидируют body через Pydantic.
- Превышение разрешённых полей (например, попытка поставить статус, который не предусмотрен) → 422 с явным сообщением.
- Конфликты (например, повторный Idempotency-Key с другим телом) → 409.

## Принципы документации

- Каждый эндпоинт в коде сопровождён `summary` и `description` для Swagger.
- Примеры тел запросов/ответов в Pydantic-схемах через `Field(examples=[...])`.
- На `/docs` будет полностью кликабельная документация.
