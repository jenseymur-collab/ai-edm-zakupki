# Чек-лист перед каждым коммитом кода

Этот чек-лист AI-агент проходит **перед** тем, как отдать тебе блок кода. Если хоть один пункт «нет» — не отдаёт, переписывает.

## 🔍 Корректность

- [ ] Все импорты ссылаются на реально существующие модули и функции
- [ ] Нет «магических» строк, не объявленных в коде или конфиге
- [ ] Нет placeholder-ов: `...`, `TODO`, `# implement later`, `should exist`, `assume`
- [ ] Все типы аннотированы (Pydantic / TypeScript)
- [ ] Все DTO явные, не `dict` без схемы

## 🛡 Обработка ошибок

- [ ] Каждый эндпоинт валидирует вход
- [ ] Каждое исключение либо обработано, либо сознательно проброшено вверх
- [ ] Каждый внешний вызов (LLM, БД) обёрнут в timeout + retry + fallback
- [ ] Логирование на критических точках (вход эндпоинта, вызов LLM, ошибка)

## 🧱 Архитектура

- [ ] Модуль не лезет в БД чужого модуля
- [ ] Модуль не импортирует приватные части (`сервис.py`, `репозиторий.py`) другого модуля
- [ ] Все вызовы LLM — только через `общее/llm_client.py`
- [ ] Нет циклических зависимостей
- [ ] Нет глобальных переменных с состоянием

## 🧪 Тесты

- [ ] Для нового кода написан хотя бы один happy-path тест
- [ ] Для критической логики (согласование, версионирование, AI) — также edge-case тесты
- [ ] LLM в тестах замокан, реальные API не дёргаются

## 🔁 Идемпотентность

- [ ] Эндпоинты, которые мутируют данные, защищены от повторных вызовов (Idempotency-Key или dedup-ключ)

## 📋 Формат отдачи

При выдаче блока кода AI-агент **обязан** сопроводить его:

1. **Что код делает** — 3–7 пунктов простым языком
2. **Риски и упрощения** — что специально упрощено и где слабые места
3. **Чек-лист для тебя** — что проверить вручную после запуска
4. **Следующий шаг** — чёткое действие («запусти `make test`», «открой http://localhost:3000»)

## 🚨 Критическое

Если хоть один из этих пунктов сорван → блок кода невалиден:

- ❌ Использован несуществующий API
- ❌ Архитектурное нарушение (DB-доступ через слой, чужой модуль напрямую)
- ❌ Скрытое предположение («должно работать», «обычно есть»)
- ❌ Pseudo-код в продакшн-блоке
