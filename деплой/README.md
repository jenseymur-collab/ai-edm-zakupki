# Деплой

Конфиги для запуска: локально и на хостинге.

## Что будет здесь

```
деплой/
├── Dockerfile              # сборка образа
├── docker-compose.yml      # локальный запуск (app + Postgres)
├── .env.example            # шаблон переменных окружения (без секретов!)
├── railway.json или render.yaml  # конфиг хостинга
└── github-actions/
    └── ci.yml              # lint + tests
```

## Принципы

- Секреты **никогда** не коммитим. В репозитории только `.env.example` с пустыми значениями.
- `docker-compose up` должно поднимать всё локально одной командой.
- `README.md` главного уровня содержит точную инструкцию по запуску — без неё ТЗ не закрыто.

## Хостинг (после Фазы 0)

Решение по хостингу будет принято исходя из:
- доступного LLM-провайдера
- требований к локализации данных (фарма-контекст может требовать РФ-хостинг)
- бюджета (для MVP — бесплатные тарифы)
