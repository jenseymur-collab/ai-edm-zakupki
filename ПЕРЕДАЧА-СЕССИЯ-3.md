## 2. АРХИТЕКТУРНЫЕ РЕШЕНИЯ (ADR — не менять без обсуждения)

- **Cyrillic identifiers**: классы, поля, функции, переменные на русском. ENV vars и SQL — ASCII.
- **SQLAlchemy 2.0 async**: `Mapped`, `mapped_column`, `async_sessionmaker`.
- **Схемы Postgres**: `"пользователи"`, `"сделки"`, `"документы"`, `"согласование"`, `"аудит"` — физические схемы в кавычках.
- **Без cross-schema FK**: ссылки между схемами — UUID-поля без `ForeignKey()` на уровне БД.
- **create_all() на старте** (не Alembic) — MVP, миграции не нужны.
- **pgvector**: расширение `vector`, поле `Vector(1536)` в модели `Эмбеддинг`.
- **OpenRouter**: единственная точка выхода в LLM — `app.общее.llm_client`. Модули не импортируют `openai` напрямую.
- **Все модели — Sonnet** (`anthropic/claude-sonnet-4-5`). Opus убран для экономии бюджета.
- **MVP**: без Alembic, без mypy, без ruff, без CI. Только то, что нужно для демо.

## 4. МОДЕЛИ ДАННЫХ (краткая шпаргалка)

### Пользователь (schema "пользователи")
`id, имя, роль(закупки/финансы/юрист/гд), email, создан`

### Поставщик, Сделка (schema "сделки")
Сделка: `id, номер(ЗК-2026-001), название, поставщик_id, ответственный_id, профиль(стандарт/малая_закупка), статус, сумма, валюта, создана, обновлена`

### Документ, ExtractedFields, Эмбеддинг (schema "документы")
Документ: `id, сделка_id, тип, номер, версия, родитель_id, активная, статус, текст, источник, загружен_кем, загружен_когда`  
ExtractedFields: `id, документ_id(unique), поля(JSONB), модель_использована, схема_версия, извлечено_когда`  
Эмбеддинг: `id, документ_id(unique), вектор(Vector(1536)), модель_использована, создан`

### МаршрутСогласования, ШагМаршрута, Виза (schema "согласование")
Виза: `id, документ_id, маршрут_id, шаг_маршрута_id, пользователь_id, решение, комментарий, дедлайн, решено_когда`

### Событие (schema "аудит")
`id, тип, сущность_тип, сущность_id, пользователь_id, данные(JSONB), создано`

- `код/backend/app/модули/сделки/роутер.py` — CRUD сделок
- `код/backend/app/модули/документы/роутер.py` — загрузка/просмотр документов
- `код/backend/app/модули/согласование/роутер.py` — визирование (принять/отклонить)

- `код/backend/app/модули/документы/схемы.py`
- `код/backend/app/модули/согласование/схемы.py`

**Ключевые эндпоинты Block B:**
```
GET  /deals                     — список сделок с пагинацией
GET  /deals/{id}                — карточка сделки (документы + статус согласования)
POST /deals/{id}/documents      — загрузка документа (text body для MVP, без S3)
GET  /documents/{id}            — просмотр документа + extracted fields
POST /documents/{id}/approve    — виза: принять/отклонить с комментарием
GET  /dashboard                 — агрегат: сделки по статусам, просроченные, новые
```

**Бизнес-логика согласования:**
- При загрузке договора → автоматически создать Виза по подходящему маршруту (выбор по тип_документа + сумма_сделки)
- При POST /approve → записать решение в текущий шаг, перейти к следующему или закрыть маршрут

### Block C — AI Layer (3 часа)
**Файлы создать:**
- `код/backend/app/модули/документы/сервисы/извлечение.py`
- `код/backend/app/модули/документы/сервисы/поиск.py`
- `код/backend/app/модули/сделки/сервисы/проверка.py`
- `код/backend/app/модули/сделки/сервисы/задержки.py`
- `код/backend/app/модули/документы/сервисы/сравнение.py`

**AI-эндпоинты:**
```
POST /documents/{id}/extract    — LLM извлекает поля из текста → ExtractedFields
POST /search                    — семантический поиск по вектору (pgvector cosine)
GET  /deals/{id}/completeness   — LLM проверяет полноту пакета документов
GET  /deals/{id}/delays         — LLM ищет задержки/риски в визах/дедлайнах
POST /documents/compare         — LLM сравнивает 2 версии документа (diff + summary)
```

**Промпты (хранить прямо в коде):**
- Извлечение: `извлеки из договора поля: номер, дата, стороны, сумма, предмет, срок, реквизиты → JSON`
- Поиск: cosine similarity через pgvector, top-5 результатов
- Полнота: `для сделки типа X проверь, все ли документы на месте по чеклисту`
- Задержки: `проверь визы и дедлайны, выяви просрочки и риски`
- Сравнение: `сравни два текста договора, выяви изменения, оцени риск`

/dashboard          — 3 виджета: сделки по статусам / просроченные визы / последние события
