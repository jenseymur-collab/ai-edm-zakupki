## Лог работы

### Block D — Эмбеддинги (ЗАВЕРШЁН)

**Новые файлы:**
- `код/backend/app/модули/документы/сервисы/эмбеддинги.py` — сервис эмбеддингов:
  - `создать_или_обновить_эмбеддинг(документ_id, сессия)` — upsert вектора для одного документа
  - `backfill_эмбеддингов(сессия)` — генерация для всех активных документов без вектора

**Изменения:**
- `роутер.py` — добавлен `BackgroundTasks`: после загрузки документа автоматически запускается `_фоновый_эмбеддинг()` (не блокирует ответ)
- `ai_роутер.py` — новый эндпоинт `POST /ai/embeddings/backfill`: починит семантический поиск для seed-данных

**Как проверить:**
1. `http://localhost:8000/docs` → `POST /ai/embeddings/backfill` → Execute (~20-30 сек)
2. `POST /ai/search` с запросом "амоксициллин" → должны появиться результаты
