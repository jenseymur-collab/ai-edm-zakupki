# Промты — журнал общения с AI-агентом

Здесь хранится история диалогов с AI-агентом, которые мы вели при разработке. По итогу проекта эта папка ляжет в основу `PROMPTS.md` (требование ТЗ).

## Как ведём

- Один файл на одну тематическую сессию (например, `2026-05-05_фаза-0-старт.md`).
- В каждом файле: дата, цель сессии, ключевые решения, важные промпты дословно.
- Не нужно копировать каждое сообщение — фиксируем то, что **повлияло на код или архитектуру**.

## Что точно записываем

- Промпты, которые дали хороший результат (чтобы повторить).
- Промпты, которые сработали плохо (чтобы не повторять).
- Решения, которые принял AI без явного указания (важно для аудита).
- Места, где Ольга поправила AI — чтобы видеть зоны слабости модели.

## Шаблон файла

```
# [Дата] — [Тема]

## Цель сессии
...

## Ключевые промпты
> промпт 1
→ результат, оценка

## Решения
- ...

## Что забрали в код
- ...
```
