## Промты сессии

### Промт 1
> Привет. Прикрепляю профиль, ТЗ от руководства и safety-протокол. Это старт MVP AI-EDM для фарма-закупок. Нам нужно согласовать ключевые архитектурные решения перед тем как начать писать код: стек, архитектуру, LLM-провайдера и план разработки.

### Промт 2

### Промт 3

### Промт 4

### Промт 5
> А модели — я хотела везде Opus, это самая передовая модель.

### Промт 6

## Принятые решения (ADR)

| Решение | Выбор | Обоснование |
|---|---|---|
| Архитектура | Модульный монолит | Микросервисы = +7–9 ч инфраструктуры при 36-часовом бюджете |
| LLM-провайдер | OpenRouter | Anthropic API не работает с российской картой; у пользователя есть ключ OpenRouter с $90 |
| Модели | Sonnet 4.5 основная, Opus 4.6 только для сравнения версий | Opus везде = $50–100 на грани бюджета; Sonnet даёт сопоставимое качество на структурированных задачах |
| Стек | FastAPI + SQLAlchemy + PostgreSQL + pgvector + Next.js + Tailwind | Зрелый стек, хорошая документация, pgvector избавляет от отдельного векторного хранилища |

## Скоуп MVP (полный, не урезан)

- 7 типов документов
- Единая карточка сделки со связями
- Workflow согласования с маршрутами и визами
- Версионирование документов
- Семантический поиск (pgvector)
- AI-извлечение полей из документов
- Анализ задержек виз
- Проверка полноты пакета
- Сравнение версий договора с AI-комментарием
- Дашборд с KPI

**Вне скоупа MVP:** мобильный UI, реальная авторизация.
